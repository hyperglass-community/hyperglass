## Message Customization

Hyperglass keeps user-facing messages configurable so each deployment can describe its own service. The following messages may be adjusted as needed:

| Parameter                       | Type   | Default Value                                            | Description |
| :------------------------------ | :----- | :------------------------------------------------------- | :---------- |
| `messages.authentication_error` | String | Authentication error occurred.                           | Displayed when Hyperglass is unable to authenticate to a device. Usually, this indicates a configuration error. |
| `messages.connection_error`     | String | Error connecting to \{device_name\}: \{error\}           | Displayed when Hyperglass is unable to connect to a device. Usually, this indicates a configuration error. Use `{device_name}` or `{device}` to show the device name, and `{error}` to show the connection error. Both device placeholders work. |
| `messages.device_command_error` | String | The query command failed on \{device_name\}.             | Displayed when a device rejects a command or denies permission to run it. `{device_name}` identifies the device. |
| `messages.general`              | String | Something went wrong.                                    | Displayed when an error occurs that Hyperglass did not anticipate or handle correctly. If this appears in production, enable [debug logging](/installation/environment-variables.mdx) with `HYPERGLASS_DEBUG` and review the logs before opening a bug report. |
| `messages.invalid_input`        | String | \{target\} is not valid.                                 | Displayed when a query target's value is invalid in relation to the corresponding query type. `{target}` will be used to display the invalid target. |
| `messages.no_input`             | String | \{field\} must be specified.                             | Displayed when a required field is not specified. `{field}` will be used to display the name of the field that was omitted. |
| `messages.no_output`            | String | The query completed, but no matching results were found. | Displayed when Hyperglass can connect to a device and execute a query, but the response is empty. |
| `messages.not_found`            | String | \{type\} '\{name\}' not found.                           | Displayed when an object property does not exist in the configuration. `{type}` corresponds to a user-friendly name of the object type (for example, 'Device'), `{name}` corresponds to the object name that was not found. |
| `messages.rate_limited`         | String | Too many requests. Please try again later.               | Displayed when a query is over the [query rate limit](/configuration/config/query-limit), or a client is over a [share](/configuration/config/share) quota, with HTTP 429. |
| `messages.share_invalid_expiry` | String | Choose one of the offered times to keep the shared result. | Returned with HTTP 400 when a [share](/configuration/config/share) request's `expiresIn` is not one of `share.timeout_choices`. |
| `messages.share_not_allowed`    | String | This result can't be shared.                             | Returned with HTTP 403 when a [share](/configuration/config/share) is requested for a result of a directive with `retain: false`. |
| `messages.share_not_found`      | String | This shared result does not exist or has expired.        | Returned with HTTP 404 for a missing, expired, deleted or hidden [share](/configuration/config/share), or a wrong delete token. |
| `messages.share_pending`        | String | This result is still being completed. Try again in a moment. | Returned with HTTP 409 when a share is requested while the result's enrichment is running. |
| `messages.share_result_expired` | String | This result is no longer cached. Run the query again to share it. | Returned with HTTP 404 when a share is requested for a result that is no longer cached. |
| `messages.share_too_large`      | String | This result is too large to share.                       | Returned with HTTP 413 when a snapshot would be larger than `share.max_size`. |
| `messages.share_unavailable`    | String | Sharing is unavailable right now. Please try again later. | Returned with HTTP 503 when `share.max_entries` snapshots exist, or when Redis is full (`maxmemory` with `noeviction`). |
| `messages.share_unsupported`    | String | This shared result was saved in a format this version can't show. | Returned with HTTP 422 for a share stored in a snapshot version this version doesn't read. |
| `messages.request_timeout`      | String | Request timed out.                                       | Displayed when the [`request_timeout`](/configuration/config.mdx#top-level-parameters) time expires. |
| `messages.target_not_allowed`   | String | \{target\} is not allowed.                               | Displayed when a query target is implicitly denied by a configured rule. `{target}` will be used to display the denied query target. |
| `messages.feature_not_enabled` | String | \{feature\} is not enabled. | Deprecated. Accepted but not displayed. Setting it logs a warning at startup. No removal release is scheduled. |
| `messages.invalid_field` | String | \{input\} is an invalid \{field\}. | Deprecated. Accepted but not displayed. Setting it logs a warning at startup. No removal release is scheduled. |
| `messages.invalid_query` | String | \{target\} is not a valid \{query_type\} target. | Deprecated. Accepted but not displayed. Setting it logs a warning at startup. No removal release is scheduled. |
| `messages.no_response` | String | No response. | Deprecated. Accepted but not displayed. Setting it logs a warning at startup. No removal release is scheduled. |

##### Example

```yaml filename="config.yaml"
messages:
    general: Something went wrong.
```
